# 🏫 ระบบบริหารจัดการและสื่อสารข้อมูล ศูนย์พัฒนาเด็กเล็ก เทศบาลเมืองบางใหญ่ จังหวัดนนทบุรี (Bang Yai Child Center MIS)

โครงการนวัตกรรมดิจิทัลพัฒนาเว็บแอปพลิเคชันเพื่อบริหารจัดการและสื่อสารข้อมูลของศูนย์พัฒนาเด็กเล็ก เทศบาลเมืองบางใหญ่ จังหวัดนนทบุรี รองรับการใช้งาน 3 บทบาทหลักตามแนวคิด **Single Source of Truth** และ **Privacy by Design**

## 🚀 คุณสมบัติและโมดูลหลัก 8 โมดูล (8 Core Modules)

1. **ระบบทะเบียนเด็กและผู้ใช้งาน (User & Child Registry)**: จัดเก็บและเชื่อมโยงข้อมูลเด็ก ประวัติผู้ปกครอง ครูประจำชั้น และห้องเรียน
2. **ระบบเช็กชื่อการเข้าเรียน (Quick Attendance Check-in)**: ครูเช็กชื่อ มา/สาย/ลา/ขาด ได้รวดเร็วใน 1 คลิก พร้อมสรุปอัตราการมาเรียน
3. **ระบบคำขอแจ้งลา (Leave Request & Approval Workflow)**: ผู้ปกครองยื่นคำขอแจ้งลา (ป่วย/กิจ) พร้อมติดตามสถานะ ครูอนุมัติได้จากหน้าเว็บ
4. **ระบบข่าวสารและประกาศ (News & Communications)**: เผยแพร่ข่าวสารกิจกรรมและประกาศสำคัญ ติดตามสถานะการรับทราบ
5. **ระบบรายการอาหารประจำวัน (Daily Meal Plan)**: แสดงเมนูอาหารเช้า อาหารกลางวัน อาหารว่าง พร้อมแจ้งเตือนข้อมูลการแพ้อาหาร
6. **ระบบบันทึกกิจกรรมประจำวัน (Daily Activity Record)**: บันทึกภาพถ่ายและรายละเอียดกิจกรรมการเรียนรู้ประจำวัน
7. **ระบบบันทึกพัฒนาการรายบุคคล (Child Development Record)**: ประเมินพัฒนาการ 4 ด้าน (ร่างกาย, อารมณ์-จิตใจ, สังคม, สติปัญญา) ตามมาตรฐานปฐมวัยแห่งชาติ
8. **แดชบอร์ดผู้บริหารและรายงาน (Executive Dashboard & Export Reports)**: แสดงตัวชี้วัด กราฟแนวโน้ม ออกรายงานพิมพ์ได้ และส่งออก CSV

## 💻 วิธีการเปิดใช้งานระบบ (How to Run)

### วิธีที่ 1: เปิดผ่าน Python Web Server (แนะนำ)
เปิด PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
python -m http.server 3000
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

### วิธีที่ 2: เปิดไฟล์ index.html โดยตรง
ดับเบิ้ลคลิกไฟล์ `index.html` หรือเปิดผ่านเว็บเบราว์เซอร์ (Chrome / Edge / Firefox / Safari)

## 🛡️ มาตรฐานความปลอดภัย & Privacy by Design
- **RBAC (Role-Based Access Control)**: จำกัดการเห็นและแก้ไขข้อมูลตามบทบาทผู้ใช้
- **Audit Logging System**: บันทึกประวัติการเข้าถึงและการเปลี่ยนแปลงข้อมูลสำคัญย้อนหลัง
- **WCAG 2.2 Accessible & Mobile-First**: รองรับการใช้งานบนมือถือ แท็บเล็ต และคอมพิวเตอร์อย่างสะดวก
